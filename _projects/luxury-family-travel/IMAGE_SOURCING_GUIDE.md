## How to find official photos for each property

For each destination, find **3-5 real photos** showing:
1. 📸 **The iconic "drool" shot** — infinity pool, best view, signature feature
2. 🛏️ **Room/villa** — where guests sleep
3. 🍽️ **Dining** — family meal setting
4. 🌊 **Experience** — pool, beach, activity
5. 👨‍👩‍👧‍👦 **Family moment** — kids enjoying the property

## How to add an image

1. Open the hotel's gallery page (links above)
2. Right-click the best image → "Open image in new tab"
3. Copy the URL
4. Open `public/data/image-map.json`
5. Add it under the destination ID:

```json
{
  "bali-001": {
    "hero": {
      "url": "https://fourseasons.com/...photo-url...",
      "source": "Four Seasons Resort Bali at Sayan",
      "sourceUrl": "https://www.fourseasons.com/sayan/photos-and-videos/",
      "license": "official"
    },
    "gallery": [
      { "url": "...", "source": "Four Seasons Sayan", "sourceUrl": "...", "license": "official" },
      ...
    ]
  }
}
```
