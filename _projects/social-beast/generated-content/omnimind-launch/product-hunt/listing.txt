# Product Hunt Listing — OmniMind v0.3.0

## Title
OmniMind — Memory that doesn't forget for your OpenClaw agents

## Tagline
The memory layer for OpenClaw that finally lets agents remember conversations, learn from experience, and evolve overnight. 100% local, MIT license, runs on a Pi.

## Description

Your OpenClaw agents have a 20-minute memory. OmniMind fixes that.

Three storage layers under the hood:

• LanceDB: vector storage for semantic search across every conversation
• Kuzu: graph DB for entity relationships and procedural knowledge
• SQLite: provenance tracking for full audit trail of what your agent knows

Every night, the Memify worker compresses episodic memories into higher-level summaries. Your agent gets smarter over time without you doing anything.

No cloud dependencies. No API keys. No Mem0 bills. Just local memory that actually works.

MIT license — fork it, embed it, ship it. Runs on anything Node.js runs on (including a Raspberry Pi 4).

Install: openclaw plugins install @openclaw/omnimind
GitHub: https://github.com/apifenylabs/omnimind

## What people are saying

"Finally — a memory layer that respects privacy and works offline. No sending my agents' memories to some cloud API." — Early user

## Tech Stack
• Vector: LanceDB (embedded)
• Graph: Kuzu (embedded)
• Provenance: SQLite (embedded)
• Embeddings: Ollama (bge-m3 default)
• Self-evolution: Memify nightly compression
