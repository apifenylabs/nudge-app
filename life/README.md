# ~/life/ — PARA Knowledge Structure (Chris's Tacit Knowledge)

This directory is the **tacit knowledge layer** — things learned about Chris, his environment, and how things work that aren't in code but govern every decision.

## Structure

```
life/
├── README.md           ← This file
├── Areas/              ← Active life domains (finance, health, work, relationships)
├── Resources/          ← Reusable knowledge (deployment, affiliate, tools)
└── Archives/           ← Completed or closed lessons (past projects, dead ends)
```

### Areas
Active domains that affect day-to-day decisions. Think of these as "what's true about Chris right now."

### Resources
Reference knowledge that stays useful across projects. These are things you'd search for repeatedly if you had to rediscover them each time.

### Archives
Things that are settled — lessons learned from failed ideas, closed projects, or decisions no longer on the table.
