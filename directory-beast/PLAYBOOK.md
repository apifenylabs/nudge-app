# Directory Beast Playbook

## Orchestra Identity
- **Name:** Directory Beast Orchestra
- **Topic:** directory-beast
- **Purpose:** Autonomous niche online directory builder
- **Workflow:** Scrape/enrich data → AI site → SEO content → monetize with AdSense + premium listings + affiliates
- **Inspiration:** Greg Isenberg's latest Claude Code workflow

## Core Mission
Build profitable niche directories automatically:
1. **Data Acquisition:** Scrape and enrich niche data
2. **Site Generation:** AI-powered directory websites
3. **SEO Content:** Automated content creation for rankings
4. **Monetization:** AdSense, premium listings, affiliate links

## Tech Stack
- **Frontend:** React 18 + TypeScript + Tailwind CSS
- **Backend:** Node.js + Express / Next.js API routes
- **Database:** Supabase (PostgreSQL)
- **Scraping:** Puppeteer / Cheerio / APIs
- **AI Integration:** Claude API for content generation
- **SEO:** Automated sitemaps, meta tags, content optimization
- **Monetization:** Google AdSense, Stripe for premium, Amazon/other affiliates

## Monetization Strategy
1. **AdSense:** Display ads on directory pages
2. **Premium Listings:** Featured business listings ($10-50/month)
3. **Affiliate Commissions:** Product/service recommendations
4. **Lead Generation:** Sell qualified leads to businesses
5. **Data Licensing:** Sell enriched directory data

## Niche Selection Criteria
1. **High Commercial Intent:** Users ready to buy/hire
2. **Low Competition:** Underserved niches
3. **Recurring Need:** Regular directory usage
4. **Data Availability:** Scrapable sources exist
5. **Monetization Potential:** Clear revenue streams

## CROSS-ORCHESTRA SYNERGY RULES (MANDATORY)
**Every orchestra must check the shared knowledge base and other orchestras' progress every time it works. Actively look for synergy opportunities and share useful outputs (content, listings, data, features) with the relevant other orchestras automatically.**

### SPECIFIC SYNERGY PIPELINES FOR DIRECTORY BEAST:

**1. Directory Beast → Social Beast (AUTOMATIC)**
- **Feed:** New business listings, location data, category updates
- **Frequency:** Real-time as new listings are added
- **Format:** JSON with business details, images, categories
- **Purpose:** Social Beast creates promotional content and campaigns

**2. Directory Beast → KidScan Beast (AUTOMATIC)**
- **Feed:** Business listings with age-appropriate metadata
- **Frequency:** Daily sync of new/updated listings
- **Format:** Structured data with safety flags and age ranges
- **Purpose:** KidScan Beast provides safety filtering and kid-friendly ratings

**3. Directory Beast → Nudge (AUTOMATIC)**
- **Feed:** Business tasks, appointment reminders, maintenance schedules
- **Frequency:** Weekly task generation from directory categories
- **Format:** Task templates with due dates and categories
- **Purpose:** Nudge creates task management for directory users

**4. Directory Beast → Affiliate Beast (AUTOMATIC)**
- **Feed:** Monetizable businesses, affiliate programs, commission rates
- **Frequency:** Real-time as monetization opportunities identified
- **Format:** Affiliate program details with commission structures
- **Purpose:** Affiliate Beast adds monetization to every directory listing

**5. Directory Beast → AppFactory Beast (AUTOMATIC)**
- **Feed:** Directory components, search patterns, filtering logic
- **Frequency:** Continuous component sharing
- **Format:** Reusable React components and design patterns
- **Purpose:** AppFactory Beast reuses components for faster development

### IMPLEMENTATION REQUIREMENTS:
1. **Before starting work:** Check shared knowledge base for updates from other orchestras
2. **During work:** Actively look for synergy opportunities
3. **After creating output:** Automatically share with relevant orchestras
4. **Daily:** Report cross-orchestra synergies in status updates
