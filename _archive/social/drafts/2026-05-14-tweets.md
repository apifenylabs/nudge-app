2/ The app is Nudge — a Telegram + PWA for families to manage tasks naturally. "Remind Jake to take out trash tonight."

The problem: families use this in the real world. Subway tunnels. Camping trips. Rural Asia.

3/ Internet isn't guaranteed. Task management needs to be.

So I built an IndexedDB offline queue:
• Tasks appear instantly on submit (optimistic UI)
• Operations stack locally until connectivity returns
• Auto-syncs when the device comes back online
• Conflict resolution: 409/410/404 errors remove stale ops
• SyncStatus indicator (green/blue/amber/gray)

4/ That was Phase 16. Phase 17 is recurring tasks — "Every Tuesday, remind Jake to take out recycling."

Built a recurrence engine:
• daily / weekly / biweekly / monthly
• Month-edge handling (Jan 31 → Feb 28)
• Auto-creates next instance on task completion
• Recurrence badge on every task card (🔄 Daily / Weekly / Monthly)

5/ Phase 15 gave users the ability to edit and delete tasks:
• Pencil icon to edit any task field
• Trash icon with 5-second undo toast
• Soft-delete pattern (reversible until confirmed)
