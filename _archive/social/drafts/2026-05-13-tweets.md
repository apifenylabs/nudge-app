## POST 2 — LINKEDIN POST

One afternoon. Six niche travel sites. A one-command affiliate injection system.

I run EV Charging Asia, Luxury Family Travel, Apifeny AI, and three other niche sites. Each has dozens of pages, each needs affiliate links, and each was using placeholder IDs that needed replacing before going live.

The obvious approach? Open each file, search-and-replace, repeat 100+ times. Boring, error-prone, and a massive time sink.

The better approach? Build once, automate forever.

I wrote two scripts:

1. `affiliate-inject.sh` — a universal one-command injection tool that replaces every placeholder ID across all 6 sites at once. It centralizes affiliate IDs for all programs (Klook, Viator, Booking.com, and 45 others I researched and scored).

2. `affiliate-audit.mjs` — scores each site 0-100 on affiliate readiness, so I know exactly what's missing without manual inventory.

Plus: FTC-compliant affiliate disclosure banners deployed to every site footer. Not optional.

Here's why this matters: I didn't just save myself an afternoon. I built a system that makes future site additions equally fast. New niche site? Add it to the config, run one command, done.
