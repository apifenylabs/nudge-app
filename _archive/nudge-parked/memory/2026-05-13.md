## What was built

### Telegram Inline Mode (`@nudgebot` in ANY chat)
Users type `@nudgebot <task>` in any Telegram conversation and get rich inline results:

1. **Quick Add** — One-tap task creation with NLP-parsed details
2. **Assign to family member** — Shows variants for each family member
3. **Schedule variants** — Today/Tomorrow/This Weekend/Next Week options
4. **Connect prompt** — Unconnected users see sign-up CTA

### Distribution Play
Inline mode makes every Telegram chat a Nudge funnel. Users discover @nudgebot without installing anything.
