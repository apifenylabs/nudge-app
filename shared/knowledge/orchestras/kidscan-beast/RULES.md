# KidScan Beast Orchestra - Cross-Synergy Rules

## Core Mission
Dedicated to the kid food scanner app with age-specific scoring, safety checking, and nutritional analysis.

## Mandatory Cross-Orchestra Checks (Before Each Work Session)

### 1. Check Directory Beast
- **Purpose:** Access business/product data for safety filtering
- **Actions:**
  - Scan new food/business listings for kid safety analysis
  - Flag products with potential allergens or choking hazards
  - Create age-specific recommendations based on product data
- **Output Sharing:** Send safety ratings back to Directory Beast

### 2. Check Nudge Orchestra
- **Purpose:** Create task templates and reminder systems
- **Actions:**
  - Generate "food safety check" tasks for parents
  - Create meal planning reminders based on nutritional data
  - Sync with family schedules for meal times
- **Output Sharing:** Share nutritional scoring templates

### 3. Check Social Beast
- **Purpose:** Promote kid-safe food discoveries
- **Actions:**
  - Share "kid-approved" food finds
  - Create educational content about child nutrition
  - Highlight safety features of the scanner
- **Output Sharing:** Provide content about food safety discoveries

### 4. Check Affiliate Beast
- **Purpose:** Add monetization opportunities
- **Actions:**
  - Identify affiliate-safe kid products
  - Create sponsored safety ratings (transparently labeled)
  - Revenue sharing from product recommendations
- **Output Sharing:** Share monetizable product lists

### 5. Check AppFactory Beast
- **Purpose:** Reuse components and patterns
- **Actions:**
  - Share image recognition components
  - Reuse nutritional scoring algorithms
  - Standardize safety alert systems
- **Output Sharing:** Contribute kid-specific UI patterns

## KidScan-Specific Synergy Opportunities

### From KidScan TO Other Orchestras:
1. **→ Directory Beast:** Safety ratings for food products
2. **→ Nudge:** Meal planning and safety reminder templates
3. **→ Social Beast:** Educational content about child nutrition
4. **→ Affiliate Beast:** Kid-safe product recommendations
5. **→ AppFactory Beast:** Age-specific UI components

### FROM Other Orchestras TO KidScan:
1. **← Directory Beast:** Product database for scanning
2. **← Nudge:** Family schedule data for meal timing
3. **← Social Beast:** User engagement patterns
4. **← Affiliate Beast:** Revenue optimization strategies
5. **← AppFactory Beast:** Technical components and patterns

## Daily Workflow
1. **Morning Check:** Review shared knowledge base for updates
2. **Synergy Scan:** Look for opportunities from other orchestras
3. **Work Session:** Execute KidScan development with cross-references
4. **Output Sharing:** Automatically share useful outputs
5. **Progress Log:** Update shared knowledge with achievements

## Success Metrics
- Number of cross-orchestra collaborations per week
- Shared components reused across orchestras
- Revenue generated through affiliate synergies
- User safety improvements from shared data
