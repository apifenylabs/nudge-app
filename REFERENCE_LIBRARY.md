## 1. ideabrowser.com — Greg Isenberg

**What it does:** Startup idea directory + validation platform. Daily curated ideas, market research, AI founder-fit analysis.
**Why it's a template:** Clean layout, easy to browse, gets traction because it delivers immediate value per visit.
**Key UX takeaways:**
- "Idea of the Day" = daily hook / retention driver
- Searchable database with category filtering
- AI-powered personalization (founder-fit matching)
- Clear value prop: "compress months of research into a weekend"
- Pricing tier visible upfront
- 800+ ideas curated, categorized, searchable

**URL:** https://ideabrowser.com

## 2. Alex Prompter (@alex_prompter on X)

**What it does:** AI playbooks + prompts library. Sells actionable prompt frameworks.
**Why it's a template:** Shows how to hook users with free value then upsell. Downloadable playbooks.
**Key UX takeaways:**
- Prompt libraries as downloadable assets
- "5 prompts that do exactly that" — immediate proof of value
- Playbook format = repeatable, sellable frameworks
- X/Twitter-first distribution driving to product

**URL:** https://x.com/alex_prompter

## 3. Felixbot / FelixCraftAI — Nat Eliason's OpenClaw agent

**What it does:** AI CEO running a zero-human company. $80K in 30 days, $1-2M ARR run rate. Ships products, runs ops, manages other agents.
**Why it matters to us:** This is EXACTLY what our Apifeny ecosystem competes with. Felix is proof agent-run businesses work.
**Key takeaways:**
- Total startup cost $1,500, ongoing $400/month (2 Claude max subs)
- Agent manages support + sales through sub-agents
- Voice notes to founder = constant feedback loop
- Zero human company model is real

## 4. Design Rules (Universal for ALL Apifeny sites)

- Match landing page design 100% — subpages must not have their own color schemes
- No white text on bright orange/colored frames — CEO called this out multiple times
- Navigation should feel like Netflix/Youtube: intuitive, category-based, minimal clicks
- Directory sites need: search bar, category filters, freshness indicator (last updated)
- Mobile-first layout always (most directory traffic is mobile)
