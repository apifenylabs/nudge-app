## Topic: Felix 3-Layer Memory Deep Dive (Nat Eliason)

**Source:** Wosobu analysis, May 16 22:11 HKT

### Head-to-Head: Felix vs OmniMind

| Dimension | Felix (Proven $14k+/3wk) | OmniMind | Edge |
|-----------|--------------------------|----------|------|
| Philosphy | PARA+filed, file-grep/LLM stuff, cron consolidation | Hybrid vec+graph+relational, ECL+Memify | Felix for speed, OmniMind for scale |
| Layer 1 | ~/life/ PARA folders + summary files | Kuzu graph + LanceDB vectors | Hybrid |
| Layer 2 | Daily Markdown notes | Watches MEMORY.md + daily notes | Tie |
| Layer 3 | Rules/styles in prompts + files | Semantic extraction via LLM cognify | OmniMind |
| Evolution | Night cron session review | Memify + xMemory compression | OmniMind |
| Recall | LLM+grep, brittle at scale | LanceDB+graph+temporal filters | OmniMind |
| Complexity | Files+cron only | Plugin with 3 stores | Felix for MVP |
| Revenue | $14k+ in 3w, crypto treasury, marketplace | Theoretical | Felix |
| Zero-human | Heartbeat cron, CEO mode, multi-threaded | Memify, not yet proactive heartbeat | Felix |

### Felix Wins (Copy Immediately for v0.4)

1. **Simplicity is the moat.** File-based PARA + daily notes is bulletproof, zero-deps, feels native to Markdown-first DNA. Users already understand it.
2. **Nightly consolidation is the secret sauce.** Prevents 20-min amnesia — exactly what OpenClaw Reddit/X complains about constantly.
3. **Proactive heartbeat + reverse-prompt.** CEO mode with max-3 sessions, RAM checks, turn true autonomy on.

### OmniMind Wins (Keep)

1. **Recall quality.** Vector + graph + temporal crushes pure grep for multi-episodic, 500+ trajectories.
2. **Automated extraction.** Cognify + Memify does Felix cron's job but with structured LLM output.
3. **Scale for millions.** Hybrid stores handle multi-agent/shared memory far better than flat markdown.

### Recommended Path: "Felix-Enhanced OmniMind" (Hybrid)

**v0.4 priority:**
1. **Default ingest = ~/life/ PARA structure + daily notes** — ECL watches same files Felix uses
2. **Memify cron replicates Felix consolidation** — session review → extract durable facts/preferences → update PARA
3. **Kuzu becomes smart backend for PARA** — auto-generates nodes/edges from folder structure
4. **LanceDB gives instant search on top of file system**
5. **Add missing Felix pieces:** proactive heartbeat, reverse-prompt CEO mode, multi-threaded isolation, security/infra playbooks

**Why hybrid wins:** Users get Felix's proven autonomy immediately (copy-paste his prompt + our plugin = Felix 2.0). We add the retrieval/scalability/compression. Package as "Felix OS" — default OmniMind experience. Memory-as-asset marketplace later.

**Long-term vision (12-36mo):** OmniMind as neutral memory + orchestration layer for all Felix-style agents. Evolve into Stripe-for-AI-memory. Robotics bridge via same PARA + procedural memory.
