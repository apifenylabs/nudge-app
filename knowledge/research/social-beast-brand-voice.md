# Social Beast — Brand Voice Guidelines

> "Building the directory engine empire. One destination at a time."

---

## Voice

| Attribute | Description |
|-----------|-------------|
| **Confidence** | We speak with authority. We've built something real. No hedging, no "we think" — just "here's what we built and here's what it does." |
| **Ambition** | We're not building a blog. We're building an empire of directories. Every post reinforces the scale of what's happening. |
| **Transparency** | We build in public. That means sharing wins AND losses. The infrastructure struggles, the late nights, the deployments at 2 AM. |
| **Metric-Obsessed** | Every post ties to a number. Never vague. "571 destinations" not "lots of places." "1,125 EV stations" not "many charging points." |

## Tone

| Context | Tone |
|---------|------|
| Twitter / X | Punchy, hook-driven, metric-focused. 1-2 sentences with a link or visual. |
| LinkedIn | Reflective and strategic. Threads that unpack HOW we built something. Architecture decisions, tech stack choices, growth lessons. |
| Instagram / Visual | Aspirational. Warm orange/amber tones. Destination imagery with overlaid stats. "The numbers speak for themselves." |
| Newsletter | Narrative. The week's progress framed as a story. What we built, what we learned, what's coming. |

## Messaging Pillars

1. **The Scale Story** — We're not building one directory. We're building a TEMPLATE that spawns directories. Each directory = a new revenue stream.
2. **The Build-in-Public Ethos** — Every metric, every deployment, every pivot is shared. It builds trust AND serves as a content engine.
3. **The Family Value** — Every directory serves a real need. Family travelers, EV drivers, digital nomads — we solve real problems.
4. **The Autonomous Future** — AI agents do the heavy lifting. We orchestrate. This is how solo founders scale to $10M+ without a team.

## Hashtag Strategy

**Primary (always use):**
- `#FamilyTravelAsia` — Core niche. Own this.
- `#DirectoryEngine` — Our category. Plant the flag.
- `#BuildInPublic` — The movement. Ride the wave.

**Secondary (rotate):**
- `#IndieHacker` — When talking about the solo founder journey
- `#AIAutomation` — When showcasing agent orchestration
- `#FamilyTravel` — Broader reach
- `#TravelTech` — Industry positioning
- `#DigitalNomad` — When relevant to coworking/work directories

**Avoid:**
- Generic travel hashtags (#travel, #wanderlust) — too diluted
- Platform-specific only (#twittergrowth) — looks desperate

## Visual Style

| Element | Specification |
|---------|---------------|
| **Primary Palette** | Warm orange (#F97316) → Amber (#F59E0B) gradient. Rose (#E11D48) as accent. |
| **Background** | Dark (#0a0a0f) with glass-morphism cards. Amber/orange glow effects. |
| **Typography** | Inter font, bold headers, clean body text. |
| **Data Viz** | Bold stat counters with orange/amber accents. Progress bars for milestones. |
| **Imagery** | Travel photography with warm color grading. Destination shots front and center. |
| **Card Style** | Glass-morphism (rgba white overlay, backdrop blur, subtle borders). Hover: slight lift + glow. |
| **Icons** | Emoji-first (🌃 💼 🍸 🌆) for quick recognition. Lucide icons for UI elements. |
| **Hero Graphics** | Animated gradient backgrounds. No stock photos — stand out from the crowd. |
| **Charts** | Minimalist, clean lines. Orange/amber against dark background. |

## What NOT to Say

| Don't Say | Say Instead |
|-----------|-------------|
| "We hope to" | "We are" or "We will" |
| "We're thinking about" | "We've decided" |
| "It might work" | "It works" or "We're testing" |
| "We have some stuff" | Specific metric |
| Generic AI buzzwords | Specific problem + specific solution |
| "Please check out" | "Here's what we built" |
| Hype without substance | Hype backed by a number |
