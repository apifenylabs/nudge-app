## 3. Mandatory Monetization Rules (EVERY DIRECTORY)

### Rule 1 — Deep Link Engine
- Must use the Deep Link Engine built in Phases 1-5.
- All affiliate links must use deep links (not generic homepage links).
- Specific product IDs where possible (Klook, Viator, Agoda, Booking, etc.).

### Rule 2 — Price Comparison Widget
- Every product/trip/recommendation page must show a Price Comparison Widget.
- Compare Klook vs Viator vs Agoda vs Booking (varies by category).
- Widget increases conversion by showing the user the best deal immediately.

### Rule 3 — Contextual Affiliate Recommendations
- Every recommendation must include cross-sell suggestions:
  - Travel: "Book this activity + nearby luxury villa"
  - AI tools: "Book this AI tool + related playbook"
  - Sports: "Book this event + recommended hotel"
  - Wellness: "Book this retreat + spa add-on package"
- Bundles increase average order value and per-click revenue.

### Rule 4 — Shorten the Distance to Dollars
- Every click should be within 1-2 steps of conversion.
- No dead-end content pages. Every page must have at least one affiliate CTA.
- Use "Book Now", "Check Prices", "Compare Deals" as primary CTAs.
- Inline affiliate links within editorial content (not just sidebar widgets).

### Rule 5 — Track and Optimize EPC (Earnings Per Click)
- EPC is the north star metric for monetization.
- Track EPC per directory, per page type, per affiliate partner.
- Regular optimization cycles (weekly review, monthly deep dive):
  - Low EPC pages → redesign CTAs, reposition affiliate links
  - High EPC pages → identify pattern, replicate across other directories
- EPC targets (to be refined over time):
  - Travel directories: aim for $0.50-$2.00 EPC
  - AI directory: aim for $1.00-$5.00 EPC

## 5. EPC Tracking & Reporting

```
EPC = Total Affiliate Revenue / Total Clicks
```

- Track per directory
- Track per page type (listing, detail, comparison)
- Track per affiliate partner (Klook, Viator, Agoda, Booking, etc.)
- Report EPC in every nightly report
- Flag directories with EPC < $0.30 for optimization
