## Paperclip AI Research (21:48-21:50 HK)

**Time:** 21:48-21:50 HK
**Budget:** Under $0.15, DeepSeek-chat only.

### Key discovery
- Our `paperclip-coordination.md` and `paperclip-config.json` are homemade documentation, NOT the real Paperclip AI platform from github.com/paperclipai/paperclip
- Real Paperclip: MIT-licensed, self-hosted Node.js server + React dashboard for agent coordination
- Features: org charts, budgets, governance, ticketing, audit logs, agent onboarding, heartbeat execution, mobile management
- Designed to work with OpenClaw, Claude Code, Cursor, Codex

### Installation plan provided
- **Install:** `npx paperclipai onboard --yes --bind lan` (1 command)
- **Integration:** Create 7 agents (one per beast), wire OpenClaw via webhook, migrate task files to tickets
- **Benefits:** Real ticketing vs text files, budget limits with hard stops, audit trails, mobile control
- **Risk:** Embedded Postgres fine for dev, can migrate to Supabase Postgres for production
- **Cost to install:** $0 (local, existing machine)
