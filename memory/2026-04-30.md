## "See More" Blank Page Fix (23:34 HKT)

**Bug:** Clicking country "See all" links on landing page caused blank page.

**Root cause:** Country row "See all" links used `#full-grid` anchor — Next.js `<Link href="#full-grid">` causes hash navigation bug where page renders empty. No country filtering applied.

**Fix deployed:**
1. Changed all country row "See all" links from `#full-grid` to `/search?country=Japan` (URL-encoded proper hrefs using `href={{ pathname: '/search', query: { country: row.name } }}` and `encodeURIComponent`)
2. Changed Top Picks "See all" from `#full-grid` to `/search`
3. Changed Parent Tips "See all" from `#full-grid` to `/search`
4. Updated search page (`_client.tsx`) to read `?country=` from `useSearchParams()` and initialize country filter state from URL param
5. Wrapped search page client component in `<Suspense>` for SSG compatibility (build was failing without it)

**Files changed:**
- `family-travel-directory/app/page-content.tsx` — 3 SectionHeading linkHref values changed
- `family-travel-directory/app/search/_client.tsx` — Added `useSearchParams`, useState init from URL, wrapped in Suspense
- `family-travel-directory/app/search/page.tsx` — Wrapped `<SearchPageContent>` in `<Suspense>`

**Deployment:** 3 deploys (manual fix → build fix → production alias). Live at https://www.familytravelasia.com
