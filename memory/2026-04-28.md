### Client-Side Exception Fix (12:12 HKT)
- **Root cause:** `lib/supabase-browser.ts` used `require('@supabase/ssr')` inside the client-side function. `require` doesn't exist in the browser — throws `ReferenceError: require is not defined` on any page calling `createBrowserSupabaseClient()`
- **Fix:** Replaced `require('@supabase/ssr')` with top-level `import { createClient } from '@supabase/supabase-js'` (CJS-compatible, already a dependency)
- `@supabase/ssr` is now reserved exclusively for server-side code, never browser
- **Prevention rule:** All browser Supabase client code must use `@supabase/supabase-js` directly
- Deployed and verified fix live at 12:14 HKT
