## 22:37 HKT — OmniMind Project Launch

**New workspace created:** `~/workspaces/omnimind/`
**Project:** Zero-Knowledge AI Memory API — persistent memory layer for AI agents.

### Phase 1 (Lean MVP) — Built and Tested

- **Auth:** Static `MEMORY_API_KEY` + `X-User-ID` header (no Supabase JWT or encryption in v1)
- **Backend:** FastAPI (Python 3.12), async-only
- **Vector store:** Qdrant 384-dim cosine distance (`memories` collection)
- **Embeddings:** `sentence-transformers/all-MiniLM-L6-v2` with hash-based fallback for dev
- **Database:** SQLite (dev) / PostgreSQL (prod), dual mode via config
- **Rate limit:** Token bucket, 10 req/sec per user_id
- **Strict schema validation:** Pydantic v2, fail hard on invalid data
- **Endpoints:** POST/GET/DELETE memories, POST query, GET ping, GET health

### Key Design Decisions
- **sentence-transformers** wrapped in `run_in_executor` to avoid blocking async event loop
- **Hash fallback** allows backend to start instantly in constrained envs without torch/transformers (which OOM-killed in WSL)
- **SQLite dev** mode avoids Docker dependency for local development
- **Phase 1 stores plaintext** in `memories.text` column; `crypto_utils.py` was removed and will be resurrected for Phase 2
