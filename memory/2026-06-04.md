### Critical Bugs Found & Fixed

**1. @property inside __init__ (hyperliquid_connector.py)**
- Root cause: `@property` decorators for info/wallet were placed INSIDE the `__init__` method body (lines 73-79). Python treats them as method-local function definitions, the SDK wallet/address never initializes, _wallet stays None, get_balance() always returns 0.0.
- Fix: Moved both @property definitions AFTER the __init__ method closing.
- Fix: get_balance() checks spotClearinghouseState balances as last-resort fallback (SPOT USDC, not just perp margin).

**2. Balance not written to state (main_bot.py)**
- Root cause: `state["balance"]` was never updated from live `connector.get_balance()`. The local variable `balance` was correct but `state["balance"]` contained stale data from bot_state.json.
- Fix: Added `state["balance"] = round(balance, 2)` at line 858 right after live fetch.
- Also added type guard in save_state() to prevent None/string/0 values from passing through.

**3. s_size → szi field name (position_guard.py)**
- Root cause: HL API returns `"szi"` (signed size) not `"s_size"`. HTTP fallback in update_state() threw KeyError on `'s_size'` when positions existed.
- Fix: Changed all `pos.get("s_size", ...)` to `pos.get("szi", ...)` in both HTTP sync and WS handler.
- Also renamed variable from `s_size` to `szi` for clarity.
