## Key Lessons
1. **Sub-agent token limits**: Complex file rewrites (500+ line page.tsx) need to be split: read first, plan changes, apply targeted edits. Don't try full rewrites in one sub-agent call.
2. **Stripping content from summaries**: Always strip all content fields from sub-agent output summaries. Metal-core bio, penis enlargement, affiliate disclosures, and long emoji-rich descriptions must all be truncated or removed before storing in summary.
3. **CEO-managed files vs sub-agent chaos**: Sub-agents frequently break existing structure when editing complex pages. Reverting to git baseline and manually re-applying only the intended changes is the safest approach for high-churn files.
4. **Vercel deployment tip**: After env var changes, Vercel auto-deploys. No manual trigger needed. Check deployment status via CLI.
