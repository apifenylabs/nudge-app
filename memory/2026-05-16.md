### How `loadChunk` works (worth remembering)
- Three storage destinations per chunk:
  1. LanceDB: vector embedding + full text
  2. Kuzu: MemoryNode + RELATED_TO edges (via LLM extraction or manual graphData)
  3. SQLite: provenance + content_hash for dedup
- LLM extraction is best-effort (try/catch, graceful fallback to empty/summary-only)
